AIRPORTS TO BRIEF

Window = earliest ETA − margin to latest ETA + margin (margins in AIRPORT BRIEFS → Settings, default 60 / 120 min). ETOPS alternates use the OFP's own validity period; check whether it already includes a margin. Creating briefs keeps NOTAM/weather text you already pasted.

NOTAMs + WEATHER FROM THE WEB

2a. OPEN FAA NOTAM SEARCH2b. OPEN AVIATIONWEATHER.GOV
3. In each of those two tabs click this same bookmark, paste the list, wait:
FAA → TFD
One-time setup: drag the gold button FAA → TFD into the bookmarks bar (Mac: Cmd+Shift+B shows it). It runs in your own browser tab on the FAA site, one request per location, then sends the results here.
Zero results is not the same as no NOTAMs. The FAA site may not hold NOTAMs for every foreign location; such locations are shown in amber. Unofficial route: it can stop working if the FAA changes its site. The official routes are the FAA NMS API and the ICAO NOTAM API (both need registration).

FIRs / OVERFLIGHT EASA CZIBs

Tick-boxes are your own tracking, saved on this device. The window to read FIR NOTAMs is entry − margin to exit + margin. The OFP does not list the FIR you depart from.

MOVING MAP

Aircraft position is dead-reckoned from the OFP's elapsed times for the take-off time above (a web page has no aircraft position feed). Dashed circles = OFP range ring around each ETOPS alternate.

VERTICAL SECTION — WIND / TEMPERATURE BY ALTITUDE

Move over the chart to read wind and temperature.
Winds and temperatures are the OFP forecast at 7 levels (10,000 to 41,000 ft) interpolated between route points. Brown = grid MORA from the OFP. Climb/descent line is approximate. No turbulence/icing data: use SIGMET/SIGWX.
